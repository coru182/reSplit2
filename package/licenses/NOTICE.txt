reSplit2 (PPSA99064): TimeSplitters 2 (US Xbox) statically recompiled for the PS5

An unofficial fan project, not affiliated with or endorsed by Free Radical Design, Deep Silver, Plaion, Eidos,
Microsoft or Sony Interactive Entertainment. It contains none of the game's files: they are read from the player's
own disc image. The game's program in it is recompiled from the US release's default.xbe.

What is in the app, and under which terms

- reSplit2's own code, the PS5 host (ps5/: app shell, entry, input, audio, the in-game menu) and its changes to the
  SDK: GPL-3.0 (reSplit2-GPL-3.0.txt). The PS5 host is reKing's (GPL-3.0), which follows reUndr's PS5 host by
  bystritskiy (MIT, reUndr-MIT.txt); the first start's disc image unpacking and its screen (ps5/disc_image.c,
  ps5/screen_ps5.c) are adapted from reUndr's (MIT, reUndr-MIT.txt). The home screen icon is reSplit2's own drawing,
  under the same GPL-3.0.
- The Athelas SDK by Shagg (MIT, Athelas-MIT.txt): the game template, the XDK library replacements and the
  renderers this port builds on.
- XboxXBE-Recomp by TGP482, the recompiler and runtime (MIT, XboxXBE-Recomp-MIT.txt).
- Liberation Sans, the menu's font (SIL Open Font License 1.1, LiberationSans-OFL.txt).
- Dear ImGui (MIT), toml++ (MIT), stb (public domain / MIT, stb-LICENSE.txt), the Khronos Vulkan headers (Apache-2.0 / MIT),
  and glslang 15.4.0 (BSD / MIT / Apache-2.0, glslang.txt).
- RADV from Mesa (MIT and others, Mesa-license.rst), built with PS5_Vulkan's recipe, which with its native link
  recipe and the PS5 Platform library from the PS5_PayloadSDK fork is GPL-3.0-or-later (PS5_Vulkan-LICENSE.txt,
  PS5_PayloadSDK-LICENSE.txt). The combined executable is therefore subject to the GPL-3.0-or-later.
